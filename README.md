# Claude Code First PR

A project workspace for Claude Code experiments and learning.

## Overview

This repository is a practice project for submitting your first pull request with Claude Code and GitHub. It contains work samples and documentation for Claude Code projects.

## Contents

- `design_handoff_costai/` - Design handoff resources
- `prd_sourceanalysis.docx` - Product requirements document
- `.gitignore` - Git ignore rules for common file types

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/LeeJoonSeok0516/claude-code-first-pr.git
   cd claude-code-first-pr
   ```

2. Create a new branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. Make your changes and commit:
   ```bash
   git add .
   git commit -m "description of changes"
   ```

4. Push to GitHub and open a pull request:
   ```bash
   git push origin feature/your-feature-name
   ```
